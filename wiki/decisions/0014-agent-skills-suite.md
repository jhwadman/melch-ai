# ADR 0014: Coding agents learn the framework from a shipped Agent Skills suite

**Decided (2026-09-24):** `skills/` ships SKILL.md skills in the package, installed by `melchizedek-skills` into `.claude/skills/` and `.agents/skills/`; each skill's prose is generated by the Scribe syndicate from a brief kept in `skills/briefs/` and reviewed by a person.

**Instead of:** an MCP server with list/run tools, a plugin per platform, a page of docs

How it works: [The agent-skills suite](/operations/agent-skills.md)
